# SVT circuit graphics (SVG)

All files are drawn on Mark's heart-conduction-system.svg (8000 x 8000 units) and use the video palette. Each file has named groups so layers can be hidden or recolored in Illustrator/Figma:
heart, conduction-system, av-node-glow, avnrt-circuit / avrt-circuit, accessory-pathway, direction-arrows.

- avnrt-circuit-full-heart.svg: whole heart, small re-entry loop around the AV node.
- avnrt-circuit-av-node-zoom.svg: the zoomed AV-node view used in the video and Short 4.
- avnrt-circuit-overlay-only.svg: just the loop + arrows on a transparent 8000x8000 frame; drop it exactly on top of heart-conduction-system.svg.
- avrt-circuit-accessory-pathway-full-heart.svg: orthodromic AVRT (AV node -> His -> left bundle -> lateral Purkinje -> accessory pathway -> left atrium), pathway in teal inside the lateral wall.
- accessory-pathway-only-full-heart.svg: heart with the accessory pathway, no circuit.
- avrt-circuit-overlay-only.svg: AVRT loop + pathway + arrows on a transparent 8000x8000 frame.
- av-junction-schematic-avnrt.svg: the simplified atria / AV node / His / ventricles schematic with the AVNRT loop.

Conduction tracts are in the muted beige used in the video; the direction arrows are an addition for static use (the video showed direction with a moving amber dot).
